Parent function for init.c that is called upon in trashctl.c. Used to initialize all aspects of trashctl.

Initalizes all necessary components of trashctl and determines what action to take based on user-input.

Parameters
[in]argcAn integer representation of the number of commands passed to trashctl.
[in]argvAn array of char pointers that contain each inputted argument.
Returns
If the operation is successful, 0 is returned. Otherwise, a 1 is returned on failure.
